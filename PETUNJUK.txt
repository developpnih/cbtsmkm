CBT SEKOLAH - PETUNJUK PASANG

BACKEND  : Code.gs  (Google Apps Script + Google Spreadsheet)
FRONTEND SISWA : index.html, style.css, script.js
FRONTEND ADMIN : admin.html, admin.css, admin.js
BERSAMA  : config.js (tempat URL Web App), template_soal.docx

1. Buat Google Spreadsheet baru > Extensions > Apps Script > tempel isi Code.gs
2. Jalankan fungsi "setup" sekali (izinkan akses Spreadsheet & Drive)
3. Deploy > New deployment > Web app (Execute as: Me, Access: Anyone) > salin URL
4. Buka config.js, ganti GANTI_DENGAN_URL_WEB_APP dengan URL tadi (cukup di satu file ini)
5. Upload semua file frontend ke hosting (GitHub Pages / Netlify)
6. Siswa buka  : alamat-anda/index.html
   Admin buka  : alamat-anda/admin.html  (password awal: admin123, ganti di Pengaturan)

Kelas: tambahkan dulu di menu Data Kelas (atau klik "Ambil dari Data Siswa").
Kelas tujuan ujian dipilih lewat kotak centang di Mapel & Ujian:
  Semua kelas | Semua kelas X / XI / XII | per kelas (mis. X TSM 1, X TSM 2)
Update Code.gs: Deploy > Manage deployments > Edit > New version

UPDATE PERFORMA: ganti Code.gs di Apps Script > jalankan "setup" sekali > Deploy > Manage deployments > Edit > New version.
Upload ulang config.js (jangan lupa isi URL Web App), style.css, script.js, admin.js ke hosting.

JADWAL UJIAN: di Mapel & Ujian isi "Jadwal mulai". Siswa terlambat otomatis dikurangi durasinya
(waktu selesai = jadwal mulai + durasi). Kosongkan jadwal jika ujian bebas kapan saja.

PENGAWAS RUANG: halaman pengawas.html (+ pengawas.js, pengawas.css)
1. Admin > Ruang & Pengawas: tambah ruang (Nama Ruang = username, contoh R1) + password
2. Admin > Data Siswa: isi kolom ruang tiap siswa (CSV kolom "ruang"), atau cari/filter lalu klik "Atur Ruang (yang tampil)"
3. Pengawas buka alamat-anda/pengawas.html, login dengan username ruang. Pengawas HANYA bisa mematikan alarm siswa di ruangnya.

UPDATE ALARM: ganti Code.gs (Deploy > New version), upload ulang script.js dan admin.js.

GAMBAR SOAL: gambar kini disimpan di sheet "Gambar" (tanpa Google Drive, tanpa izin tambahan, tanpa berbagi publik)
dan dikirim langsung ke siswa saat ujian dimulai. Soal bergambar lama (yang tersimpan sebagai tautan Drive) perlu diupload ulang.
Bank Soal > tombol "Lihat" untuk pratinjau soal beserta gambarnya.

DAFTAR HADIR & BERITA ACARA (file baru: dokumen.js, dokumen.css)
- Siswa login berhasil -> otomatis tercatat hadir untuk ujian yang aktif/sedang dibuka sesuai kelasnya.
- Selesai ujian per mapel -> siswa diminta tanda tangan di layar. Jika belum, tombol "Tanda tangan" muncul di menu siswa.
- Admin: menu Daftar Hadir dan Berita Acara (pilih ruang + mapel). Pengawas: tab Daftar Hadir dan Berita Acara di pengawas.html.
- Isi kop surat, logo kanan, kota/kab, kode, dan judul di Admin > Pengaturan.
- Cetak: tombol "Cetak" -> pilih Save as PDF atau printer (ukuran A4).

UPDATE (Daftar Hadir tabel, Pengaturan Alarm): upload ULANG SEMUA file frontend ke hosting:
 index.html, style.css, script.js, admin.html, admin.css, admin.js, pengawas.html, pengawas.css, pengawas.js, dokumen.js, dokumen.css
 (config.js jangan ditimpa). Lalu ganti Code.gs -> Deploy > Manage deployments > Edit > New version.
Menu admin "Pengaturan Alarm": ON/OFF alarm pelanggaran (hanya admin). Jika OFF, pelanggaran tetap dicatat tanpa bunyi.

UPDATE DAFTAR HADIR: kolom Kelas & Nilai sebelum Tanda Tangan, Proktor/Pengawas -> Pengawas 1/Pengawas 2, logo kini UPLOAD (Admin > Pengaturan).
Upload ulang: admin.js, admin.css, dokumen.js, dokumen.css, script.js, pengawas.js. Ganti Code.gs lalu Deploy > New version.
Logo lama berupa link perlu diupload ulang sebagai gambar.
